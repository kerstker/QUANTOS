# 内层组合选择、整体账户与配对前向

2026-09-10，研究开发增量，未部署。承接[统一路线](../plans/2026-09-09-profitability-validation.md)的组合与证据环节。

## 实现与预注册范围

- 从原实验内层已计算候选按既有净成本分数选最多三个组件；不读取外层收益决定组件。
- 四分之一权重网格，最多 16 组，含每个单模型及空仓。逐组件应用原置信度扣减后合并预测，交给同一个成本、风险与持仓决策。不是分账户净值相加。
- 原资金 1,500 USDC、原风险规则；内层按净损益减 1,500 倍最大回撤排序，等分时优先空仓/更少组件。全部尝试留在独立 TrialLedger；中断计失败，不重新抽样。
- 选择回执先冻结，再拟合外层。组合和内层单模型分别回放费用/滑点 4/5、4/10、8/5 bp，共六组。零成交、失败、无稳定净增量分别给出停止结论。
- `process-v2` 在三折、每个搜索组内部重新选组件及权重，再测试整个账户。保留旧过程材料；新增对照仍明确为已用历史技术研究。
- 内外层组件预测分别缓存，绑定计划与输入摘要；记录预测准备及逐次回放耗时。恢复检查缓存形状、全部回执、账本状态和模型/权重绑定。
- 组合与内层单模型的配对预测同时追加；同一冻结模型产生的预测不回写。组合前向目录、十四天成本账户与原单模型观察分开，不迁移或重置旧窗口。
- 新组合账户的持仓继续使用历史组合的成本风险规则；空仓、组合、内层单模型各三组成本。实际执行费用、独立有效样本及稳定盈利没有据此验收。

计划绑定源码、输入面板、训练/验证/测试分区、候选、成本和预算。分区校验标签在后续分区开始前可用。外层不反馈原搜索。

## 流程与前端

新自动流水线：主研究 → 原压力诊断 → 内层组合 → 三折过程对照 → 原验证包 → 原模型观察 → 配对组合观察 → 检查点。
旧完成流水线不重跑；可用“运行组合研究”“运行过程对照”“启用组合观察”显式启动新增阶段。

Runner 仅增加两个受限研究种类及对应操作；Console 投影不输出模型训练矩阵。Studio 展示权重尝试、失败、成本后增量、对齐的账户曲线、耗时、配对预测、成熟进度与缺口。
停止观察保留预测，可能使已冻结窗口无法完成；不会填补旧预测来获得通过。

## 验证与边界

测试先复现缺少组合阶段、缓存/检查点冲突、固定阈值误拦截组合、缺少配对前向等问题，再实现修复。
已完成的专项包括：现金与反向信号净额账本、权重在外层前冻结、外层标签变动不改内层选择、失败恢复与身份冲突、真实 Runner 来源绑定、接口字段和前端曲线时点对齐。
完整验收与真实冻结数据结果将追加到本记录。当前专项通过不替代完整 canonical 门禁。

目前是有限预测组合，不覆盖独立交易策略袖套、跨账户资本或 maker 排队。真实场所校准和自然时间盈利证据仍有外部依赖。研究结论/记忆/有限 QWEN 角色是下一增量，不借此标为完成。
