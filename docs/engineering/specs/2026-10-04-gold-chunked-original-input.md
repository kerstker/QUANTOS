# 原输入分块留存与原研究入口衔接

承接[原连续采集分段](2026-10-04-gold-public-segment-producer.md)，服务于
[既定单市场闭环](../plans/2026-09-28-ai-factory-closed-loop.md)。本批完成离线
原件载体及现有有界输入的兼容衔接，不代表长期原生执行、完整发布或现场验收。

## 实际行为与边界

原 capture、六类 journal 及资金费原件逐段写入固定 SHA256 文件名，原文件
字节保留；有序 manifest 引用全部分段，重复内容可共享文件但不删除原段位置。
首段配置独立冻结，避免迭代器通过共享对象改写来源身份。原采集器的准备接口
逐段提供输入，不累计全部展开正文；旧 from_session 接口的准入预算保持。

使用原私有目录、排他写入、fsync 和原只读文件核验器。封存前及完整消费后核对
全部文件、inode、目录成员、摘要与源码身份；缺件、替换、外链、额外成员和未读完
全部段均拒绝。中断保留原文件及 INCOMPLETE 记录，不产生完整 manifest。

新载体明确预算：最多 4096 段、36864 个内容文件、1 MiB manifest、显式总字节
预算且上限 32 GiB；每个文件仍受原 16 MiB 限制。这些是离线存储边界，不提高
原执行的 64 段、16 MiB 输入、节点、journal 消息、环境或结果上限。

有限输入还原后沿原 assemble、固定 request、JobQueue、RunRegistry 和 TrialLedger
执行；超过 64 段的载体拒绝进入此兼容入口。没有新现金账本、平行试验库或新
经济权限。载体始终标记 FROZEN_ORIGINALS_NOT_EXECUTION_VALIDATED，replay_ready、
economic_eligible、submission_enabled 均 false。存储完整不证明行情连续或回测有效。

## 收尾位置

完整目标沿原 F1–F5 验收，不以补丁数量计完成率。长期输入的原生直接消费、
结果分块、执行状态有界化和检查点恢复仍须完成；本批不将 S1 标成完成。
同版完整发布、现场恢复和真实 Demo 闭环仍须验收。盈利策略单独研发；系统须能
正确通过或拒绝证据，不能为完成工程降低锁定 OOS、统计、风险或交易授权门。
30 天是当前黄金研究协议的样本要求，不是所有工程工作的统一等待期；协议要求
保持，合成段不冒充自然时间。其他市场单列，机构异机延期不记 PASS。
