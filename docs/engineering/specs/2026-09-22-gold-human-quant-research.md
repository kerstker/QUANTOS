## 交易事实输入与关联

先支持离线、无凭证的结构化导入，原始文件只读，以摘要关联衍生产物；真实文件
不得加入仓库。没有样本前只定义标准化 JSON 合同，不猜测 CSV 列名或本地时区。
具体 CSV 转换器必须针对用户提供的脱敏表头及样本回归验证。

事实至少包括 venue、environment、account_ref、symbol、position_side、trade_id、
order_id、exchange_time_ms、observed_at_ms、side、price、quantity、commission、
commission_asset、venue_reported_realized_pnl、source_hash。数值用有限 Decimal
字符串，时间为明确 UTC 毫秒。数据窗、来源方式和完整性声明单独保存。

- 成交身份含场所、环境、账户、品种和成交编号；相同事实重放幂等，冲突编号拒绝。
- 双向持仓分别识别 LONG/SHORT，单向 BOTH 不假定每次 SELL 都在平多。
- 不从余额差推断交易利润；充值、提现、内部转账与资金费独立分类。
- 交易所报告已实现盈亏不是全账户收益。佣金资产不同不得直接相加成 USDT。
- 成交流与资金流水可能重复描述手续费/已实现盈亏，不双记；外部流水用于核对，
  模拟只使用唯一 V2 账本，不创建第二个永续会计引擎。
- 没有初始持仓、余额及完整现金流，不能宣称重建账户权益、收益率或最大回撤。
- 订单、部分成交、取消与止损触发分别记录。先前止损挂单不证明已退出。
- 实盘事实永不因事后风控不通过而删除；未知数据明确显示，缺口不能补成零收益。

实时阶段采用私有事件流加有界 REST 核对，启动先取快照并处理采集竞态；断流、
漏页、查询窗口边界、重复和乱序都要覆盖。私人账户信息仅用户配置的只读边界可读，
研究进程只消费最小化产物。若场所权限无法真正分离读写，标记阻塞而非扩大权限。

成交事实与信号是两种记录。人工成交关联 strategy_version/decision_id 可以由用户
标注，时间邻近只能产生待确认候选，不能自动断言属于某策略。记录接受、拒绝、

首个假设：事先确定的价格区域中出现主动卖出但价格下行受限，随后回升确认，
可能产生做多延续/反转机会。此假设不是“已识别聪明钱”，默认先测试做多一种情形。

状态为 IDLE → WATCHING → CONFIRMING → SIGNALLED → EXPIRED。
持仓与订单由执行/账户层处理，不由信号状态假装成交。输入不完整返回 DATA_UNKNOWN，
停止新增风险信号；真实持仓保护不能依赖信号进程持续在线。

版本化参数必须在运行前填写，不内置所谓最佳参数：

| 条件 | 必须固定的内容 |
|---|---|
| 区域 | 人工预登记或确定性生成；上下沿、可用时间、到期时间、失效价 |
| 方向/场景 | 趋势或反转的定义、已收盘窗口、允许交易时段 |
| 卖方压力 | 成交窗口、数量单位、历史基准与阈值；基准只用当时已知数据 |
| 下行受限 | 价格锚、允许下行范围、最小成交量与完整行情覆盖 |
| 回升确认 | 确认价格、需收盘或成交确认、最大等待时长 |
| 入场意图 | 下一可用报价、最大价差/陈旧度、限价或市价、取消时限 |
| 退出 | 初始结构止损、目标/移动退出/超时的选定规则、冲突优先级 |
| 仓位 | 单笔风险预算、现有持仓风险、数量步长、费用与滑点估计 |
| 排除 | 无效区域、重复机会、外部休市、缺数据、成本过高 |

人工区域必须在触及前记录；事后标记只用于解释，不能作为历史可交易标签。
K 线同时触及止损与止盈而缺逐笔顺序时标记执行歧义，不选有利路径。
信号确定时间不等于成交时间；不得用确认 K 线早先价格填单。
后续改变任何规则产生新试验身份，所有失败与选择记录保留。
