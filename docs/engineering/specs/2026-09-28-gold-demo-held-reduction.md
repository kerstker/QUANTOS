# 黄金 Demo 配置材料与原持仓减仓交接

## 问题与变更

黄金请求和成交已能进入原执行链，但功能验收工具的配置材料及减仓采集仍固定 BTCUSDC，无法完成黄金开仓后的继续操作。

`tools/demo_operator_setup.py` 新增显式 `DEMO_GOLD_FUNCTIONAL_SETUP_SPEC_V1`；调用方必须选择 XAUUSDT。原默认规格仍为 BTC，黄金规格要求专用的操作员登记用途，并在原安装材料验证器中核对黄金 issuer policy、profile、mandate 和订单范围。测试使用临时密钥和合成批准，没有生成或修改实际授权。运行时配置读取和 CLI 尚未完成黄金接线。

`tools/demo_functional_worker.py` 的减仓准备现在从已验证规格选择采集品种和原持仓重建品种；模板必须仅含一笔且品种与规格相符，错配在采集前拒绝。原账户身份、已成交持仓数量、原始成本、余额、新观察时间、价格网格和名义金额上限继续核对。只生成减仓任务，不签发或发送订单。
