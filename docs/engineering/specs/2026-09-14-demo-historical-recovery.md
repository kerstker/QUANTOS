## 已实现

- 驻留恢复超过原 150 秒窗口时，从原发送记录和留存的完整终态查询中选择最早有效窗口。
  时钟原文、响应摘要、原账户/提案/预留、双端 160 秒范围、150 秒窗口及跨日限制仍检查。
  查询时钟以原记录摘要绑定，所有源记录及窗口内 GAP 保留。
- 当前最新查询仍参加最终核对。后来的数量/终态冲突不能被旧的成功查询掩盖。
  恢复后的重放使用原事件身份，不能重复累计成交；没有有效历史时钟时继续阻断。
- 原回执绑定的具体失败原因进入 OMS/驻留状态，而不只返回 RECEIPT_LEDGER_UNRESOLVED。
  页面解释数据缺口、时钟窗口、缺少私有回执和其他同计价订单。
- DEMO 首屏和交易周期分别展示最新 BTCUSDC 账户观察与历史账本数量。账户已空仓时
  明确提示历史账务仍待恢复；刷新失败、过期、未来或早于周期的账户读数不标为当前空仓。
  USDT 仓位独立，多空对冲不能净额相抵为零，极小残余数量不能经浮点舍入消失。
  API 形状、账本状态、自动完成标准与首次登记入口没有放宽。
