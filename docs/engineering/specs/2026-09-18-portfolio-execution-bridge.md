调仓任务、一次实际 Demo 自动往返及现金核对、跨日和恢复运行验收。不能用固定买单
演示、离线目标生成或历史软件检查替代这些要求。

`live/execution/demo_request_inputs.py::task_check` 校验已安装任务，没有读取组合预测。

权益、风险、交易成本及已结算资金费求解。独立 sleeve 的加权分数明确不是仓位目标。
因此，不得直接把预测分数、诊断输出或 null 当作买入、平仓或执行许可。
