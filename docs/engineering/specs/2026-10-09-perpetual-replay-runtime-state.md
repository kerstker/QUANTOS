# 技术回放使用独立运行目录

本修复属于[首次软件发行 V1](../plans/2026-10-08-software-first-release-v1.md)的安装阻断。
研究服务的工作目录是不可变的发行代码目录，运行数据由 `QUANTOS_STATE_ROOT`
指定。技术回放之前直接使用相对路径，安装后无法读取运行目录内的行情，且可能
尝试把结果写入代码目录。

`run_replay` 现在通过既有 `runtime_state_root()` 解析固定输入和输出路径。
开发调用未设置该变量时继续使用当前目录；原绝对路径行为、输入大小与软链接
检查、结果哈希和冲突拒绝保持。代码与依赖身份仍从代码目录读取。
账本、费用、风险、参数白名单及真实交易权限均未修改。

首先在独立运行目录放入明确的合成行情、从空的只读代码工作目录调用真实回放。
原实现留下 1 FAIL / 1 PASS，失败为找不到固定行情。修复后相关五组测试
39 PASS，覆盖真实账本零残差、状态目录落盘、原默认行为、固定输入拒绝、
重复结果与冲突拒绝、受控研究入口和运行目录合同。
日志保留在任务输出 `runtime-path-fix/first-red.log` 与 `green.log`。

这些结果仅证明软件修复，未替代同版完整发行门、实际安装验证、真实数据或
独立核验。结果继续为 `TECHNICAL_VALIDATION_ONLY`，下单未启用。
