## 等价计数与解码

现有 JSON trust 模块增加 ASCII 字符串大小助手：不分配转义字符串或
字节缓冲，以原引号、反斜线及控制字符成本计数，并在超过调用方剩余
预算时停下。三处原预算器复用此计算；它只接受精确 builtin ASCII str。
非 ASCII、特殊子类继续使用各调用方原路径。原深度、节点、数值、
最大标量和最终完整 wire 大小限制保持。

身份基本值仍先经过原完整 transport 预算，再通过原严格 tag reader
和原 `_canonical_identity`。只有 none/bool/int/float64/decimal/str/bytes
的精确基本标签，才能以规范 tagged tree 的精确相等替代两次 JSON
字节序列化比较。此时两侧只含严格 builtin str/bool 字段，精确相等
等价于原 compact JSON 字节相等；整数别名、Decimal 精度表示、IEEE-754
hex、负零和 bytes 大小写规则保留。容器排序、别名、集合及递归验证
继续走原完整 JSON 比较路径。所有返回值仍是原 reader 的实际结果。
