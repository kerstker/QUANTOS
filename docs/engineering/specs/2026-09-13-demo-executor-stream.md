# 执行侧私有回执采集

2026-09-13。承接[Demo 执行计划](../plans/2026-09-12-demo-execution-completion.md)。
本批增加受保护执行侧的原始私有流采集入口，尚未安装或连接真实场所。

`tools.demo_executor_stream` 在独立执行 UID 下打开已存在的
`/var/lib/quantos-demo-executor/user-stream.sqlite3`，沿用原账户命名空间、
原 `UserStreamJournal` 和持续采集循环。缺注册表、执行身份、目录或原数据库时停止，
不从研究缓存创建、替换或认证执行侧来源。

租约子进程每次重读固定注册表及原账户命名空间，仅调用原专用 Demo 凭证读取器。
API 密钥和租约不出现在命令参数、结果、异常或日志；子进程的标准输出仅用于父进程
内存交接租约。子进程不继承代理、证书覆写和其他服务密钥，20 秒超时或取消后终止。
Websocket 固定 Demo 地址并禁用代理，错误日志不传播含租约的 URL。

唯一 REST 写请求是 listen-key POST/PUT；没有订单 POST、订单 DELETE、租约 DELETE、
签发、持仓或现金写入入口。实际原始事件和断线、重连、重复、心跳、停止继续进入原
追加日志，重复消息保留且仅统计一次唯一事件；自然重启产生的缺口不会抹去。

单次沿用 6 小时、100,000 消息和有限重连策略；日志累计上限 200,000 记录、
128MiB（预留下一条消息与 SQLite 开销），结果目录另限 1,000 文件/64MiB。
耗尽后不删除旧证据来重置预算，无法正常写结果时原日志和进程失败仍可见。

## 运行与部署接入

入口为已验收解释器运行 `python -P -m tools.demo_executor_stream --source-commit <完整源码>`。
CLI 无凭证文件、账户、地址、输出数据库或风险配置覆盖选项。
其固定目录及身份前提与[驻留恢复手册](../../runbooks/demo-resident-recovery.md)相同。

`scripts/render_demo_executor_stream_unit.py` 复用原恢复单元的隔离配置，生成明确版本的
采集单元和摘要，未安装且没有 `[Install]`。原 6 小时采集到期可以重启续采，身份验证
失败的退出码 78 不重启；累计日志预算不因重启清零。单元仍保留全部五个原安全标志。

现有研究侧采集继续原样运行；新执行侧采集没有切换它。Console 仍显示原研究副本，
执行侧向研究侧的只读发布与独立身份/注册表/凭证安装需单独完成。界面快照不能作为
受保护恢复的原始输入，不把软件入口完成等同于实际部署、真实回执或现金闭合。
