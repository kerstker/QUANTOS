# 原成本后净账户的跨批前向成熟度

基线：1294f0acb649a60572efd557cab6523145473cec。
范围：C2 原候选模型风险输入；不关闭 C1–C6 整体交付。

## 问题与最终行为

原模型的 paper_confidence 缺少成本后前向原件。已有周前向路径使用毛标记收益
加资金费，不能替代 Gold 真实成交、手续费与资金费形成的净账户。原长窗口
单批最多约 32 天，不能以一个批次或密集十秒网格冒充八个周期间。

新前向设计 V9 在原采集前锁定 net_forward_policy，保留 V1–V8 原合同和投影。
沿用原八周期要求，采用七日不重叠完整周；只有存在原非零持仓的正时间区间才
计入活动周。八周之前模型置信度仍不可用，诊断归一化成熟度单独展示。
成熟度不是盈利概率，成本后收益为负的原账户仍可具有充分观察长度。

跨批只汇总期间与材料引用。每个批次保留自己的原账户、现金身份、净网格和
资金费回执，不串接余额或合成收益；不提高原单批回放/网格预算。
原始声明必须在其观察前选定候选，后续批次绑定同一策略定义、源码/配置和
提案。必须在当前原 project cut 中找到起始声明，不能事后用历史 BACKTEST
建立前向身份。所有其他尝试和失败仍保留在原试验统计总体。

## 原件接线与边界

- SourceReports 的原读租约逐批验证原计划、输入、报告和候选，再构造原
  GoldAccountRiskInputs。逐批消费，只保留有界周回执，不累积完整账户向量。
- 每个周区间从原收据可用时间网格取净权益，手续费/资金费不另算；原向量、
  持仓、现金和资金费哈希进入回执。重叠完整周拒绝，尾部不足周不计数。
- 缺覆盖、未完成批次、缺起始声明、缺网格或持仓保持 INSUFFICIENT；未来材料、
  错候选/定义/提案、错批政策、改变净向量或权限声明拒绝。
- 净前向政策与回执验证位于中立合同，模型不反向依赖账户核验模块。原模型
  V3 绑定同一候选、净结果、cut、政策和原统计快照；较晚消费不更新已签快照。
- 原核验事实 V16、执行核验 V11、API 和 TypeScript 同步。原保留/嵌套保留
  使用拥有者端口，关闭原读租约后失效；不能由序列化成熟度声明替代原件。
- 即使技术成熟度建立，维护/衰减、搜索选择/OOS、来源与时间独立核验仍各自
  必须完成。没有新增准入、HUMAN、自签权威、订单或真实交易权限。
