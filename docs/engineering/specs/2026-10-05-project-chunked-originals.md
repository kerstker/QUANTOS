## 完整项目与原件

含显式新 Gold 分块计划的项目使用 `QUANTOS_PROJECT_RESEARCH_CUT_V2`。
旧项目仍使用 V1；V1 不接受分块计划或新的字段。项目仍由固定目录全枚举，
不接受选中 run/trial 列表，原 search/candidate/provenance、全部失败/未启动试验及
各自原 TrialLedger 全局序号保持。声明前向输入绑定也覆盖新计划。

V2 每个分块 run 保留完整 `result_material` 文件清单、每份原文件的 SHA/字节数，
保留原 report reference、manifest/failure 原文，并绑定完整有序块 manifest。
完整报告原文继续保存在原 archive/report-parts，不把原文压缩成账户摘要，
也不将所有大块 base64 嵌入小 cut。纯 retained-cut 校验核登记、全库映射、
原 manifest/全部块绑定及原生命周期；它不声称独立读取了未随 cut 携带的报告字节。

实际项目读者逐份核全原块的字节和物理身份，并沿原 Gold 全报告索引核所有 JSON 字段、
完整报告字节 SHA、原 tagged 结果 identity、原输入和源码绑定。原非授权标志保持。
全项目新的源字节/派生索引各最多 32 GiB、节点最多 100M，记录固定版本预算；
各 run 的冻结 result_storage 可更小。旧 512 MiB 原读取预算、32M retained 原文、
64M cut、16M 旧叶、100K 文件和原输入/环境上限不变。新大块单独计费，
不将旧入口上限整体提升。所有索引均为临时派生数据，不成为现金/策略或权威记录。

`ProjectResearchEvidenceReader.evidence()` 在同一读集合内返回完整 cut 和
只读完整报告视图；退出时再次核原物理集合和索引，关闭后不能继续消费。
报告缺块、额外块、链接/别名、同字节改写及身份重绑拒绝。
发布中断和原预算失败保留全部现存原件、RUNNING/OUTCOME_UNKNOWN，不能变成完成。
