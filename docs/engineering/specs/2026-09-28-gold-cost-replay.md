# 黄金成交包到 V2 成本后实验接线

实现 `tools/gold_cost_replay.py::replay_costs`，复用现有信号重算、GoldV2Strategy 和唯一 V2 模拟账本。该入口是离线 Python 接口，尚未接入 Runner 的 JSON 任务、试验归档或真实数据装配，不能称为已部署工厂功能。

输入为保留的黄金成交包、明确的单区域退出/数量计划、历史合约规则、资金费策略、可执行报价及容量帧、初始资金和显式成本模型。成交包只产生信号，不能伪造为可成交盘口。每次重算全部信号，仅处理区域产生的唯一确认信号；没有信号也执行原账本现金基线，不淘汰或遗漏该尝试。

信号时间必须出现在模拟帧中，否则拒绝，防止错过信号变成虚假零收益。非黄金市场规则/资金费/报价/容量拒绝，原引擎继续验证规则时序、成交延迟、资金费结算和现金守恒。结果完整保留原 engine result_hash、订单、账本及对账，不复制另一套净收益计算。新外层摘要绑定成交包、计划与完整模拟结果；修改费用或信号规则会改变身份。

窗口结束时仍有仓位或挂单输出 OPEN_AT_END，不强制末价平仓；FLAT_TERMINAL 只表示仓位/订单已终止，不表示盈利、批准或完整历史。原信号报告 net_pnl 仍为空，成本后数值只来自 simulation.reconciliation。所有结果维持 TECHNICAL_VALIDATION_ONLY 和 authoritative=false。

## 验证

新增测试先因入口不存在失败，再实现接口。十个集成测试覆盖真实包解析→信号→V2 成交、费用和资金费的手工金额核对、未平仓、信号时点缺失、输入覆盖缺口、错市场、身份变化、无信号现金基线、未来报价不改原决策、缺资金费拒绝及重复运行一致性。

与现有黄金策略、信号回放及 V2 模拟器联合：65 passed；新增源码和测试完整 Ruff 通过。数据、规则及费率均为明确的合成回归材料，不能作为真实 XAUUSDT 收益、账户费率、规则校准或独立经济验证证据。未改 Demo 支持范围、授权、凭证或任何订单入口。

下一步应装配有来源和时效的真实规则/可执行报价输入，并接入既有试验归档及 Runner；公开 filter profile 中缺失的乘数、账户费用和风险档位仍必须明确解决，不能用测试常数代替。

数量映射已补充[官方来源核对](2026-09-28-gold-unit-source-review.md)：线性账本按 XAU 数量使用乘数1有公开规则依据，但尚未接成带来源的规则输入，不能倒填历史可用性或推断真实账户费率/风险档位。

## 自动任务输入交接增量

新增 `tools/gold_cost_inputs.py`，将离线接口所需的固定参数冻结为有界 `GOLD_COST_INPUT_V1` JSON。只重建明确列出的原引擎值对象，精确保留 Decimal、元组、容量动作、订单过滤器/约束和风险限额；无 pickle、动态导入、可调用对象或文件路径解释。未知参数、缺成本、浮点金额、非有限数字、重复JSON键和过深结构拒绝。限制16MB、50万节点和32层，不认证来源真实性，也不替代原引擎的时序/成本/风险验证。

同时实际复现原成本报告因窗口 Decimal 不能 JSON 存储的失败；修复为先把明确的有限 Decimal 编成十进制文本，再计算外层报告摘要。原模拟器摘要不变；这是尚未部署的 V1 草稿修正，旧开发输出摘要不可复用。存储后重读可独立重算摘要，不能通过通用 `default=str` 静默吞掉未知类型。

新输入10项、成本回放11项及既有相关测试联合76 passed；完整Ruff通过。回归证明整个输入JSON往返后成本结果摘要一致，包括显式订单规则和限额的保留。仍未接入Runner/试验归档、未部署、未取得真实规则或经济资格；下一步固定路径任务应复用现有试验账本保留成功、失败及中断，不能只保存盈利结果。

## 已接入研究任务队列与本地试验留档

新增 `gold_cost_replay` 诊断任务，复用现有 JobQueue、RunRegistry、TrialLedger，唯一参数为1–1000的整数 attempt。输入位于配置状态根 `data/cache/gold_cost_replay/inputs/<attempt>.json`，输出为同根 `results/<attempt>/`，目录独占创建；API参数不接受自由路径或策略回调。Runner及登记白名单同步更新，经济准入仍为诊断用途。

输入保留原字节；正式计算前登记 PLANNED/RUNNING；解析或计算失败保存拒绝报告及FAILED账本；正常结果完整保存原V2报告后登记PASSED。PASSED只表示技术计算完成。中断可留RUNNING且无完成manifest，重试不会覆盖半成品。同一调用ID复用原队列记录，不同调用ID不能覆盖已有attempt。源代码身份必须与冻结输入一致，并在计算后复查；来源身份复用现有perpetual工具，包含实际代码摘要与环境，非调用者自述的版本即被接受。
