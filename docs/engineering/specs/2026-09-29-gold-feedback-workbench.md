# 黄金研究结果接入执行复盘和下一轮研究

原生命周期页面只显示成本实验及核验，无法从一个研究结果追踪执行复盘是否交付、是否已被后续研究引用。新增只读投影，复用原 execution-feedback 目录和 research_trigger 校验，绑定原 attempt、trial、candidate、输入和报告摘要。页面显示单批/整轮资料、成熟时间、反馈摘要及引用同一反馈的后续研究编号和状态。

缺资料显示 NO_RECORD，不推断没有成交；原报告不可用时不展示反馈；资料损坏或身份不匹配显示 UNAVAILABLE。资料范围为 TECHNICAL_REVIEW_ONLY，来源尚未认证，页面明确不能据此认定真实 Demo 成交、账户收益或经济准入。后续研究状态来自原 session，不从存在反馈推断已完成再研究。投影只扫描固定目录并设文件数/字节预算，不读取执行凭证或修改原账本。

## 验证

原真实 JobQueue 联调场景增加 API 投影：第一轮试验、合成执行反馈、第二轮研究完成后，原结果可显示原反馈和后续 attempt；反馈损坏后隐藏关联进度。新增字段先复现缺失错误再接线。后端联合96项通过、1跳过，前端结果及生命周期10项和类型检查通过，静态及卫生检查通过；API 合同同步 execution_review 字段。

本增量解决前端追踪交接，不补充独立来源权威。合成反馈和模拟模型不代表真实 Demo。未部署，也未完成工厂全天运行验收。
