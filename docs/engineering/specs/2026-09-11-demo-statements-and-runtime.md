## 软件实现

`tools/binance_demo_statement.py` 是操作员显式启动的 Demo GET 采集入口，默认不读凭证、不联网。
查询固定 Demo 地址上的时钟、交易规则、逐合约保证金档位、账户手续费、分段成交历史与资金流水。
最多30个合约、84天、每段7天、300次请求；单请求10秒、循环480秒、独立CLI子进程510秒上限。
临时网络失败单项最多重试两次，每次失败保留；已成功查询不重复执行。限流和认证拒绝立即停止。
每段达到1000行明确标记可能截断，不把有限查询成功称为完整账户历史。

固定 HTTPS、拒绝重定向；公共请求不带密钥。私有查询复用已安装受限凭证。
存储只保留白名单字段和响应摘要，不保留 API key、签名、自由文本或原始错误消息。
保留准确十进制和大整数编号；实际场所末档 INT64_MAX 名义金额仅作原始元数据，未放大交易限额。

`services/research/demo_statement.py` 负责离线校验、不可变保存和按币种归因。
资金流水以 `(incomeType, tranId)` 去重，成交以 `(symbol, id)` 去重，冲突拒绝。
手续费比较是成交报告手续费与流水中的有符号手续费之和，不将两者重复扣入现金账本。
转账、资金费、手续费和已实现盈亏分别显示；未查询成交的历史合约明确列出。
该模块不维护第二套持仓/现金账本、不推定初始余额、不把显示均价变成精确历史成本。

Console 增加 `statement`，同步 TypeScript 合同、严格解析器、API 合同测试与前端。
Studio 增加实际费用表、资金归因、历史窗口、已平仓合约范围、规则/档位/费率以及失败计数。
历史快照和读取失败仍可辨认；没有流水不显示为已经验证零收益。
