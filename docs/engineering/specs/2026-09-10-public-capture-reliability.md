# 官方数据采集：有限重试、断点与前端诊断

2026-09-10。承接[统一开发路线](../plans/2026-09-09-profitability-validation.md)。开发与隔离验证，不切换常驻服务、不改写旧自然窗口。

## 已实现

- 每个官方数据源最多三次请求，每次由独立子进程执行一次公开 GET；父进程总超时不超过 45 秒，响应不超过 256 KiB，不跟随重定向。
- HTTP 状态码、Retry-After、连接/证书/超时/格式错误结构化保留，不保存原始异常中的代理或运行环境内容。临时错误有限重试，格式和证书等永久错误直接失败。
- 429 在本次采集内共享冷却时间；恢复时从原失败回执恢复等待要求，所有请求受同一截止时间与单调时钟预算限制。
- 原每小时一次逻辑采集不变；开始在前四分钟，恢复在该小时 295 秒前。每个请求先不可变登记，再写结果；中断也消耗一次尝试，已成功源复用原接收时间。
- 剩余时间不足停止请求，过晚响应仅作诊断保留，不能成为过去观察。文件保存失败中止当前采集，不能误当网络错误重试。完成的结果不覆盖。
- 工作流可继续未结束的当前小时采集，过去缺口仍保留。状态增加最新采集摘要，Console 合同与前端类型同步；Studio 显示请求次数、重试恢复、耗时及逐源错误。旧回执没有的字段显示“未记录”。
