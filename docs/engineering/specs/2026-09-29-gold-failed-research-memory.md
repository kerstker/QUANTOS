# 失败实验进入后续研究

原连续研究只传递已完成实验，失败轮次虽消耗预算/候选，却不进入模型诊断。现在原 campaign 预留事务同时读取本计划及同采集组之前批次的 FAILED 会话，冻结为 GOLD_RESEARCH_MEMORY_V2；完成记录仍兼容 V1。

失败记录使用原输入、配置和失败收据摘要，不制造 trial_id、成本报告、收益或 NO_SIGNAL。提案未完成时 candidate_id 为 null；已完成提案但成本实验失败时保留并排除该候选。调用下一轮模型前，重新读取原会话、收据、输入和已知提案核对；损坏时不调用模型。仍最多六项、按已知时间排序，不引入新的账本。

验证使用原 FactoryStore、run_session、输入归档、模型请求和第二轮实际成本实验，模型传输为测试替身。覆盖提案失败与成本失败两类，各自核对正常续轮及原输入损坏拒绝；V2 的未来事实、评分字段、伪收益和布尔候选均在模型调用前拒绝。相关七组共 80 passed，保留一条 Starlette 弃用警告。原中断测试混用零起点与真实会话时钟，已统一测试时钟，没有放宽生产时间约束。
