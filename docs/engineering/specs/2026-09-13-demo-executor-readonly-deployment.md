执行侧私有流和起点定时器已暂停等待修复验收，既有研究采集和冻结实验未改动。

新增 `live/exchange/demo_network.py` 统一以下部署配置：

- 固定 root 管理的 `/etc/quantos/demo-submission/network.json`，使用原身份与目录
  保护检查；配置缺失默认直连，存在但损坏、越权或不合法时拒绝，不隐式回退。
- 唯一配置字段为 `schema=DEMO_NETWORK_V1` 与 `https_proxy`；代理只能是无认证、
  无路径的 `http://127.0.0.1:<port>`，或明确的 null。研究请求不能指定代理或场所。
- HTTP CONNECT 保留原 Demo TLS 主机，强制证书与主机名检查；CA 使用操作系统
  默认信任路径，忽略继承的代理与证书环境变量。禁止重定向，不新增请求重试。
- 起点 GET、listen-key 租约、私有 WSS、原订单查询、原单次提交/撤单共用此边界。
  订单准入仍经过原独立签名、风险、停机和持久化流程；配置代理不会授予交易权限。
- 私有子进程仍使用干净环境；来源摘要包含新网络模块。研究原有默认采集行为不变。
