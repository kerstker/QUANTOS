## 镜像依赖

254aedb 的两次原生 ARM64 冷构建实际摘要一致，但原 Trivy 扫描正确拒绝
运行镜像唯一一项已知漏洞：zlib 1.3.2-r0 / CVE-2026-85091。
[Alpine 官方安全库](https://secdb.alpinelinux.org/v3.24/main.json)记录
1.3.2-r1 为修复版本，固定 aarch64 APK 已通过保留代理和 TLS 实际下载核对。

Dockerfile 的构建和运行阶段显式固定 zlib=1.3.2-r1；两个 console 依赖锁由
原生成器重算，只更新 Dockerfile 源码摘要，Python 包、URL 和 hash 全部保持。
原 ARM64 双冷构建、零已知运行漏洞政策和离线冒烟仍须由新冻结版本实际通过，
不复制旧扫描结论、不增加漏洞豁免。
