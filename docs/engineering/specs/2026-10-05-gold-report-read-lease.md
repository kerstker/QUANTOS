## 核验与寿命

`PreparedGoldReport` 的构造仍执行原完整 JSON wire、结果身份和 native
绑定检查；它只接受拥有者提供的只读流式视图。三个现有 reader 将同一
拥有原件的租约内的报告包装为该视图，不改变对外报告字节或 HTTP 合同。

每次复用重验精确 native run 摘要、只读索引文件身份与完整 SHA256。
普通 Mapping 和自报核验方法继续执行原完整检查。包装不能替代原件、
只保存摘要或选中账户；构造前后也核对索引和 run 身份。

拥有者关闭后立即拒绝复用；包装属性的赋值和删除均拒绝。
退出时仍核对全部原件、目录成员、权限和只读索引。新的读取操作及冷
恢复重新打开原件、解析并核验，不共享跨操作缓存。签名、信任、期限、
当前项目、统计复算与末端时间检查继续执行。

这属于受审阅代码内部的只读视图机制，不是接受 JSON 中的 verified
标志。可信代码可直接修改 Python 内部对象的构建时威胁继续由审阅、
治理与进程边界控制；本增量不宣称抵御任意可信代码绕过。
