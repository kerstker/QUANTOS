## 安装入口

`tools/demo_operating_bundle.py` 从独立提供的材料包做首次安装，受已验收、不可变源码
位置约束。它只导入已有签发键、政策、研究声明、任务和停机数据库，不生成这些材料。
API 密钥沿用原执行侧配置，不接受包内凭证文件或额外网络地址。

清单绑定确切源码、旧注册表摘要、每个文件字节及任务内容身份。导入前核对账户、角色
分离、公私钥配对、原政策/策略/风险/授权摘要、任务时窗和上限、全包订单 ID 唯一性，
并在私有临时副本核对停机数据库原历史。原批准人、验证来源和停机记录原样保留。
账户读取在专用执行 UID 的清理环境子进程中完成，避免 root 读取 SQLite 时创建
root 所有的 WAL/SHM 辅助文件。该子进程读取原来源和完整链，不读经研究缓存转存的账户声明。

签发配置为 root:issuer 的 0750 目录，材料文件 0640；签发状态与执行侧新增状态为各自
UID 的私有文件。追加库首次创建使用原实现，已有任何安装目录、撤单库或停机库立即拒绝。
所有文件、空追加库及任务落盘后才发布执行侧公钥注册表。磁盘失败保留半成品，重复运行
不会擦除、补齐或重建旧历史；需根据现场材料单独修复。安装命令不启动服务或执行任务。
