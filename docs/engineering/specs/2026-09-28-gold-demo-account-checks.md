# 黄金执行前账户检查与报告现金恢复

## 实现

原 demo_pre_submit._venue_account_cap 与 demo_position_context.validate_origin
只接收 BTC V4 账户观察；黄金独立版本无法进入同一检查。现在两处显式接收
DEMO_GOLD_EXECUTION_ORIGIN_V1，仍先由原账户观察模型检查市场/类型/资产，
然后复用原合约映射、有限保证金阶梯和账户限额、钱包守恒与单一归属仓位核对。

没有增加下单允许品种，没有修改已安装 issuer policy 或批准资料。
账户 schema 接受不等于批准执行；原订单验证、原策略和签发门继续存在。
持仓上下文的来源恢复仍由 load_context 的受控证据和账本重放负责，
不能把测试中声明的上下文当成真实来源已验证。
