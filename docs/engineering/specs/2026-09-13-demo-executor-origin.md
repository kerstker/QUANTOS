# 执行侧账户起点采集

2026-09-13。承接[执行侧私有流](2026-09-13-demo-executor-stream.md)和
[连续持仓](2026-09-13-demo-position-continuation.md)，本批完成增量接线，未部署。

`tools.demo_executor_origin` 复用原 16 次 GET、V4 输入检查、压缩响应边界、
时间/账户/场所规则及不可变保存格式。账户从已存在的受保护私有流命名空间取得，
凭证只由原固定 root 文件读取器在子进程内读取；没有复制研究密钥或运行时替换函数。
原采集器只增加内部凭证读取组合参数，其原 CLI 和默认离线行为保持。

父进程启动一次最长 115 秒的采集子进程，清理代理、证书覆写和其他服务密钥的继承；
校验输出字节上限、起止时间、源码摘要、请求合约及账户身份，失败只保留固定原因。
实际取到的部分读取和失败沿原格式保存，超时或坏交接生成明确失败记录，不自动重试。
没有普通下单、签发、风险修改或来源认证动作。

入口使用已验收的独立执行环境：

```bash
python -P -m tools.demo_executor_origin --source-commit <完整源码> --symbol BTCUSDC
```

只支持 BTCUSDC/BTCUSDT，CLI 不接受密钥路径、账户覆写、网络地址或输出数据库。
固定输出为 `/var/lib/quantos-demo-executor/execution-origins/<symbol>`；原数据按摘要保存，
`latest.json` 只是原只读索引。全程持有独立采集锁，防止并行进程竞争最新指针；
逐层验证目录后才创建下一层，拒绝符号链接导向其他目录。结果目录限 1,000 文件/64MiB。

采集完成只表明输入观察完成，仓位是否满足后续规则仍由原准备和最终发送检查判断。
现有研究 Console 不读取这个受保护路径，其发布接线和独立签发/执行侧安装仍需完成。
