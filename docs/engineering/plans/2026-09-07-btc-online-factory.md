# BTC 在线月度工厂开发合同

本批实现前固定，2026-09-07。沿用四个OLS模型、五特征、24h标签、19.2bp阈值。
仅预测观察，不产生账户收益、成交或候选准入。已有冻结观察继续独立运行。

操作3启用在线工厂；操作2推进公开采集与全部版本的成熟标签。操作0查看状态。
不安装定时器、不切换常驻服务。在线版本首次在每日UTC00:00–00:05窗口更新，
每月最多一个不可变快照，错过的月份不补写。快照使用当日UTC00:00之前真正收到且
已落入原始冻结观察账本的标签；累计至少180样本才用全部合格样本拟合四模型。
不足时留存WAITING_TRAINING快照，下一月再评估。预测窗口外不创建月份版本。

工厂选择仅使用此前在线版本实际发出的四模型共同预测，按真实标签接收时间截断，
最近90个共同样本、至少60个；MSE严格优于零预测才选择，否则CASH；同分固定模型顺序。
不得用训练内拟合误差或原始冻结模型误差代替在线误差。月内参数与选择均不改变。
每个日预测引用月版本、候选ID与原始采集摘要；工厂目标仅为观察值，不是交易指令。

月快照先落盘再准入，重复推进可恢复同一候选；旧版本预测/标签持续保留并结算。
所有原始响应即使后续请求失败也留存，失败另存记录，不能抹掉已收到的数据。
前端显示训练进度、版本、月度选择样本及最近观察。历史冻结报告保持兼容。
