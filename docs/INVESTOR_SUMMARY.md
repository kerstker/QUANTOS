**我们造的不是「一个 alpha」,是一台会自我证伪、不自欺的机构级 Alpha 工厂。**

- 护城河 = **诚实机制 + 全流程 + 数据**,不是某个单一因子。

# 真正的护城河 — 一台不自欺的工厂

- **自主量产** — 基因组生成 + 进化因子,经诚实门禁逐一筛选。
- **诚实机制** — 多重检验 / PBO / 组合 purged CV / 无窥视 OOS / 数据泄漏机器证明。

# ⚠️ 诚实风险披露 — 请认真读

- **仅离线回测,从未实盘**(无券商、无下单)。
- 滑点为**建模值,非实测**。
- **幸存者偏差**(仅含活到今天的永续)。
- carry 是**拥挤的 yield,会衰减**。
- **尾部风险**:回撤 26% · 单日 −6.8%。
- **容量有限**,难以无限放大。

> **47.1% 是「液体子集 + 建模成本」下的历史回测数,不是对未来收益的承诺。**
