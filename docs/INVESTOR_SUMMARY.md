# 原理 ① — 机器怎么工作(不自欺)

1. **因子表达 + 防泄漏**:因子写成截面表达式树;时序算子只读过去、截面只读同期 → 构造上无未来数据;再用**机器证明**(扰动未来重算、断言不变)复核。实测 **10/10 因子证明 PIT-safe**。
2. **诚实门禁**:Deflated Sharpe(惩罚多重试验)/ PBO / **无窥视 OOS** / 组合 purged 交叉验证。
3. **核心洞察**:样本内回测是「挑出来的」(必过拟合);**无窥视 OOS = 挑时看不到测试数据**,才是唯一诚实检验。

# 原理 ② — 资金费 carry 怎么赚钱

- 永续合约靠**资金费**把价格拴在现货:多头太凶→资金费正→**多头付空头**;空头太凶→资金费负→**空头付多头**。
- **carry = 站在收钱那边**:做多资金费最负的币(空头付你)+ 做空资金费最正的币(多头付你)→ **双边都收**。
- 经济本质:**收过度杠杆人群的溢价**(给拥挤交易当对手盘),和涨跌**正交**。
- 实测**日均收 5.43 bps** 资金费(仅资金费腿年化约 13.6%)。

> 这也解释了为什么**价量因子全 null,而资金费 edge 真实**——它不预测涨跌,只收持仓溢价。
