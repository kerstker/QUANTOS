## 判断与公开证据

有用，主要适用于研究提案、证据整理、反证和操作解释。是否提升成本后收益，需要在 QUANTOS 内做同预算对照。

- [论文 v7](https://arxiv.org/pdf/2412.20138v7)首页列出 UCLA、MIT 与 Tauric Research 的作者所属机构；这不能推出项目获得 MIT 官方产品背书。论文主实验为 2024-01-01 至 2024-03-29 的科技股历史模拟，不能直接作为 BTC 永续盈利证据。
- 论文采用分析、正反研究与结构化交接；其第 12 页脚注称每次预测使用 11 次 LLM 调用和 20 多次工具调用。照搬这种分工可能增加耗时，不能据此预计 QUANTOS 更快。
- [原仓库 Reproducibility](https://github.com/TauricResearch/TradingAgents#reproducibility)保留了历史日期下新闻/社媒可能反映当前内容及输出不可完全复现的说明。但本轮进一步核查发现，[v0.4.0 更新记录](https://github.com/TauricResearch/TradingAgents/blob/main/CHANGELOG.md)已列出宏观 vintage、社媒窗口、记忆可用时间和过早复盘修复；[图执行代码](https://github.com/TauricResearch/TradingAgents/blob/main/tradingagents/graph/trading_graph.py)也在记忆读取时传入 as_of。上一轮仅据 README 推断当前实现的说明不够完整，现予更正。文档与实现需绑定具体版本复核，既不据旧说明认定新版本仍有同样漏洞，也不据修复列表认定全部路径已经无泄漏；本轮未运行上游回归或复现论文。
- 截图不能验证我们的实际费率、滑点、资金费、保证金或被动排队成交；相关结论必须由本系统唯一账本和场所证据产生。

## 最小可验证借鉴

沿用本地 QWEN，先研究少量逻辑角色，限制轮数、调用数与候选总数；不新增模型订阅或大量常驻代理。

| 借鉴方向 | QUANTOS 拟交付 | 有效性判断 |
|---|---|---|
| 多来源证据整理 | 来源、事件时间、实际获取时间、版本、支持/反对观点组成证据卡 | 来源可回查，过晚信息不能进入过去决策 |
| 正反研究 | 将反对意见转成可执行的混杂检验、成本压力或失效条件 | 产生有区分力的受限实验；不以辩论胜负选择策略 |
| 结构化交接 | QWEN 提案转换为已有有类型的假设、特征和实验规格 | 全部尝试登记、预算一致、失败可恢复 |
| 研究记忆 | 记录重复假设、失败输入与内层研究结论 | 不向原搜索泄露其外层验证结果；已看历史明确标记 |
| 人机交互 | 一条链展示来源→假设→实验→成本→组合→前向 | 用户能定位失败节点、耗时、缺口与继续/停止依据 |

建议新实验预先固定三组：固定研究流程、单次 QWEN 提案、有限角色 QWEN 提案。
使用相同数据、候选预算、成本和风险预算，并分别记录计算时间、模型调用与完整尝试数。
模型/提示词/输入输出冻结；外层结果不得返回该轮搜索。验收关注成本后增量、回撤、换手、收益集中度及跨窗口稳定性，不能只比较预测准确率。
此对照尚未实现或运行；没有增量时保留失败并停止扩展角色。

## 当前工作流与组合缺口

[流水线](../../tools/ai_factory_pipeline.py)已串联主研究、评估、完整流程比较、验证材料、自然观察与检查点。
[组合评估](../../tools/ai_factory_assessment.py)已把两个通过研究筛选的模型按 50/50 预测权重，在共享账户中比较加入和替换；状态明确是 `POST_SELECTION_DIAGNOSTIC`。
它不是在内层联合选择组件与权重的组合研究，也不代表已有两个获得经济准入的 Alpha。

下一增量应将组合构建纳入现有回测工作流：

1. 预注册有限的候选组合、权重规则、交易政策和共用风险预算。
2. 仅用内层数据选择组合；组件相关性、集中度、净持仓与净换手参与选择。
3. 在唯一账户重放合并目标持仓，处理抵消、费用、资金费与风险约束，不能相加独立策略净值。
4. 冻结整个组合及选择过程，比较外层成本压力，再记录新的自然前向预测。
5. 前端显示组件贡献、组合与基线差异、净/总敞口、成本与前向成熟度。

组合可以作为整体假设研究；组件单独历史盈利不是它具有组合价值的充分条件或普遍必要条件。
但组合仍须通过整体检验，不能把相互抵消或零成交当作有效 Alpha，也不改变既有经济准入。

## 数据、速度与执行顺序

用户要求直接使用币安交易所数据。历史下载采用[币安官方数据网站](https://data.binance.vision/)的归档及校验文件；这是官方支持的网页数据下载方式，见[官方说明](https://github.com/binance/binance-public-data)。
实时采集继续用官方公开 REST/行情流，保存原始响应与实际接收时间。历史归档的发布、修订与实际获取时间分别记录，不能把今天下载的值自动当成过去已知。

当前因果采集已经请求币安官方现货、永续、指数、资金费与 OI 接口；问题包含连接可靠性。
2026-09-10 北京时间约 05:09 读取的状态：USDC、USDT 各 6/504 有效行，缺 02:00 与 04:00 小时槽。
旧失败和冻结窗口保留；按现有完整窗口合同，缺口存在时到期也不能标记研究输入完整。
改进应覆盖截止时间内的有限重试、可诊断的错误、剩余时间预算和恢复；新版本需独立登记，不能改写正在运行的冻结实现。

加速先测量采集、特征、拟合、账本重放、LLM 各段耗时，再复用冻结数据/特征、缓存相同实验、在资源允许时并行独立计算。
历史实验计算可以优化；14 天前向与 504 小时新信息窗口是自然观察长度，不能靠更多算力提前成熟。
其他预注册历史研究可以同时推进，不能把所有开发串行等待在一个自然窗口上。本轮没有测量新的加速比。

执行优先级：修采集可靠性和缺口展示 → 组合内层搜索与整体回放 → 分段耗时及缓存优化 → 有限角色 QWEN 对照。
前向观察并行运行，P5 真实成交校准按策略需要推进；短周期/maker 研究仍依赖相应校准证据。
异机恢复按用户决定搁置，不阻塞上述研究；用户确认全规模恢复可用，旧实测记录保留，不据口头确认重写 RTO 测量结果。

### 核查与修正

- v0.4.0 的相关修复已从上述官方更新记录核实。附件引用的 77 篇/19 篇也可追溯到[综述原文](https://arxiv.org/abs/2605.19337)：19 是该作者定义的主要实证子集，最高复现等级无人达到的结论属于该子集及其分级，不是全行业审计结论。
- 9/10 等评分是主观判断，不作为架构选型量化证据；Stars、角色数量和组织命名不能替代方法增量。
- 附件把“QUANTOS 已有 NSGA-II、全部指标与完整验证门”等作为前提，不能直接采信。当前工厂有固定有界候选与三折过程比较；本轮核查的活动路径未证明 NSGA-II 已接入。BTC 单资产时间序列研究也不能把横截面 RankIC 当成必备、可直接套用的指标。
- [ResearchMemory](../../services/research/research_memory.py)现为按 alpha_id 覆盖的内存注释；工厂已有[内层候选记忆](../../services/research/ai_factory_store.py)，但两者不等于持久、不可变、带可用时间及验证分区的 ResearchEpisode。
- [旧 ResearchAgentLoop](../../services/intelligence/agent_loop.py)保留了遗留评估诊断边界。新协作能力接入现行 V2 工厂及其工具适配器，不因名称相似恢复旧评估、选型或 Paper 路径。

### 采用的部分

1. **时间上下文**：每次研究调用绑定数据快照、决策/研究截止时间、实验分区和可读工具范围。工具、缓存、检索记忆、标签与派生产物继承约束；模型不能自行扩大可读窗口。实际信息可用时间未知则明确未知。时间过滤是必要条件，还需检查标签成熟、数据修订、模型训练知识及泄漏路径，不能声称一个 as_of 字段封死全部未来信息。
2. **证据绑定的 ResearchVerdict**：结论引用真实 experiment、dataset、model/feature、backtest、cost model 与报告标识和摘要；数值从工具产物读取。缺失、错版本、错计价和不支持的论断显示缺证据，LLM 不能填写计算 PASS。数值引擎提供在已声明假设下可复核的测量，不能称为绝对真相或盈利证明。
3. **有限正反研究**：首版只设提案、反证、综合三个逻辑角色，复用现有 QWEN 与 Runner。证据、状态、成本、容量、组合是工具视角；固定规则检查由程序执行，不新增一串管理或审批代理。相同模型扮演不同角色不等于独立研究意见。
4. **研究过程记忆**：追加保存假设、机制、完整试验、结果已知时间、失败证据、父子关系与允许读取的研究分区。搜索只接收允许的内层反馈，结果后的说明用于用户阅读。若未来新研究使用已公开外层或前向结果，必须登记为新研究、把该历史标为已使用，并保留新的独立验证窗口。
5. **前端与恢复**：复用 Studio、JobQueue、TrialLedger 和检查点，展示证据、分歧、缺口、调用/计算耗时和下一实验；恢复同一角色节点不重复消耗已登记实验，不重复调用已完成的模型步骤。无需为此更换整个工作流框架。

### 不原样采用的部分

- 附件例子“外层失败 → 加 ATR > 65% → 再验证”若回到同一外层选阈值，会污染验证；阈值只能作为新预注册假设进入新研究，不能描述成已经证明的经验。
- `confidence: 0.82` 不是经校准的盈利概率，首版不用这类小数作为准入依据；显示证据完整程度和明确的不确定项。
- `approved_by: research_manager_agent`、`PAPER_TRADE`、`PROMOTE` 不作为模型可执行状态。研究结论可建议停止、修订、重新实验或准备前向观察；技术产物不改变 Paper/Live/经济准入。自然预测观察与 Paper 成交须明确区分。
- 不强制每次实验都召开完整“委员会”；普通确定性对照走原自动路径，有限角色模式作为可比较的研究选项。其是否保留由成本后研究增量与耗时共同决定。

此次整合仅更新研究评估和开发规格，上述新合同、记忆及角色流程尚未实现。
