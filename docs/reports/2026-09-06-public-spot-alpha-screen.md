# 2026-09-06 公开现货 Alpha 首批验证

结论：**BTCUSDT / BTCUSDC 的 A、B、C 均不满足推进条件；没有找到符合当前 BTC 目标的 Alpha。** ETH 的 A/B 在全区间盈利，但 2026 阶段转亏、市场调整后 Alpha 的 HAC t 值约 0.5–1.0，收益集中度高，不能作为已验证盈利策略或替代 BTC 目标自动晋级。

- `tools/public_spot_alpha_analysis.py`：不调用现货账本或回放器，使用原始 CSV 价格与 Fraction 独立重算 **144 次回放、11,887 笔成交、83,088 个净值检查点，全数精确一致**。修改手续费或净值的对抗测试会失败。
- 丢失报价、异常区间或不支持规则拒绝；不足最小额或非法成交价格保留持仓继续估值。停机不可自动重启，费用触发的阈值也在观察范围内；150 是触发阈值，不是保证最大损失。

## 仍不能据此投入实盘

1. 当前 BTC 目标没有通过的候选；历史情景并非未见 OOS，未完成冻结前向、既有多重检验及权威签署。
2. 历史交易规则区间、真实账户费用币种/折扣、成交盘口/排队/延迟仍缺证据。当前 NOTIONAL 的参考价来源存在额外场所机制；本情景用已结束分钟成交量加权均价，未取得历史参考价快照。[币安过滤器文档](https://developers.binance.com/en/docs/products/spot/filters)
3. 模型训练用当前测得耗时投影到历史 5 分钟预算，不是历史实际完成时刻。日线可用时间同样为研究假设。
4. 本次实现的是离线账户停机模型，尚未补成真实执行栈的持久累计预算、实际费用/资金费/现金流净值及 USDC 订单恢复对账。现货结果不能填补永续执行验收。
5. 全量发布门禁、独立签署权威、真实告警及前向证据仍未闭合；异机恢复按用户要求延期。

下一步优先级：停止扩大这三个规格的调参；保留失败结论。BTC 后续研究需要新的可检验信号假设和数据证据，不能为了尽快实盘修改亏损预算或放宽准入。
