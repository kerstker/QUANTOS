# Lance Breitstein — 极端失控均值回归策略 (1分钟)

> **策略来源**: Lance Breitstein, 网红交易员, $1亿+美金利润, 经 Jack Schwager (Market Wizards 作者) 验证.
> **核心理念**: 不抄顶摸底, 不追顺势——只抓极端失控后的**第一次均值回归**.
> **验证结果**: BTCUSDT 1分钟, 夏普 5.01, 最大回撤 1.8%, 胜率 53%, Alpha +$4,886 (vs B&H -$3,092).
> **压力测试**: 168 滑动窗口 54% 正收益, 参数 ±30% 全正, 费率断点 9bps.

---

## 1. 策略逻辑

```
行情出现极端失控 → 价格严重偏离均值
    ↓
等待失控结束, 价格开始向均值回归
    ↓
在回归的第一段入场 (不是抄底, 是确认回归后才进)
    ↓
价格回到均线附近 → 止盈出场
如果未回归继续失控 → 紧止损
```

## 2. 适用品种与周期

| 参数 | 值 |
|------|-----|
| 交易品种 | BTCUSDT (或其他高流动性品种) |
| K线周期 | **1分钟** |
| 推荐市场 | 高波动性市场 (山寨币、股指期货也可) |
| 不适市场 | 极低波动率、单边慢牛慢熊 |

## 3. 入场条件 (三要素 AND)

以下三个条件**必须同时满足**才触发入场信号:

### 3.1 成交量异常
```
当前K线成交量 > 20周期均量的 1.3 倍
```
- 目的: 确认"失控"是真实的、有资金推动的, 不是随机噪声

### 3.2 价格极端偏离
```
|收盘价 - EMA20| / EMA20 > 0.3%
```
- 目的: 确认价格已显著偏离均线, 回归空间充足
- 0.3% 在 1 分钟级别是较大偏离 (BTC 日均波动约 2-3%)

### 3.3 K线实体放大
```
当前K线振幅 / 20周期平均振幅 > 1.3 倍
```
- 目的: 确认"失控"K线形态——比平时明显更长的蜡烛

## 4. 方向判断

| 条件 | 方向 | 逻辑 |
|------|------|------|
| 收盘价 < EMA20 | **做多** | 价格被打压过头, 预期反弹回均线 |
| 收盘价 > EMA20 | **做空** | 价格被推升过头, 预期回落回均线 |

## 5. 入场执行

**条件满足后立即入场, 无需等下一根K线确认.**

| 参数 | 值 |
|------|-----|
| 仓位比例 | 40% (可调 25%-55%) |
| 入场价格 | 当前收盘价 |

## 6. 出场条件 (任一触发即平仓)

### 6.1 目标止盈 (优先)
```
价格回到 EMA20 附近 (偏离 < 0.3%)
```
- 这是策略的核心利润来源

### 6.2 快盈止盈
```
浮盈 > 0.15%
```
- 保护利润, 防止回归后立刻反向

### 6.3 超时止损
```
持仓 K 线数 ≥ 20 根 (20 分钟)
```
- 如果 20 分钟内未回归, 说明"失控"不是均值回归而是趋势延续, 应退出

### 6.4 价格止损
```
多头: 价格 ≤ 入场 K 线最低价 * 0.998  (跌破入场 K 线 0.2%)
空头: 价格 ≥ 入场 K 线最高价 * 1.002  (涨破入场 K 线 0.2%)
```
- 紧止损, 承认错误, 不扛单

## 7. 手续费假设

| 费率 | Alpha 影响 |
|------|-----------|
| 1bps (0.01%) | 最优 (推荐) |
| 2-5bps | 可接受 |
| 8bps | 临界 (Alpha 趋近于零) |
| ≥10bps | 策略失效 |

**重要**: 此策略依赖低手续费环境. 如果模拟器默认费率 ≥ 5bps, 需手动调整.

## 8. 关键参数汇总

| 参数 | 默认值 | 可调范围 | 说明 |
|------|--------|----------|------|
| EMA 周期 | 20 | 固定 | 均线周期 |
| 成交量阈值 | 1.3x | 0.9-1.7x | 越高信号越少 |
| 价格偏离阈值 | 0.3% | 0.2%-0.4% | 越高信号越少 |
| K线放大阈值 | 1.3x | 0.9-1.7x | 越高信号越少 |
| 仓位比例 | 40% | 25%-55% | 越高波动越大 |
| 最大持仓K线数 | 20 | 12-30 | 超时止损 |
| 快盈阈值 | 0.15% | 0.10%-0.20% | 保护性止盈 |
| 价格止损幅度 | 0.2% | 固定 | 紧止损 |

## 9. 伪代码

```python
# 每根 1 分钟 K 线执行一次

# === 数据准备 ===
ema20 = EMA(close, 20)
vol_ratio = volume / SMA(volume, 20)
candle_size = (high - low) / close
candle_spike = candle_size / SMA(candle_size, 20)
trend_20 = (close - ema20) / ema20

# === 出场检查 (如果持仓) ===
if has_position:
    # 条件1: 回到均线
    if abs(trend_20) < 0.003:
        close_position("目标止盈")
    # 条件2: 快盈
    elif unrealized_pnl_pct > 0.0015:
        close_position("快盈止盈")
    # 条件3: 超时
    elif bars_held >= 20:
        close_position("超时")
    # 条件4: 止损
    elif (is_long and low <= entry_bar_low * 0.998) or \
         (is_short and high >= entry_bar_high * 1.002):
        close_position("价格止损")

# === 入场检查 (如果空仓) ===
if not has_position:
    vol_ok = vol_ratio > 1.3
    price_far = abs(trend_20) > 0.003
    candle_big = candle_spike > 1.3
    
    if vol_ok and price_far and candle_big:
        if trend_20 < 0:
            open_long(position_pct=0.4)
        elif trend_20 > 0:
            open_short(position_pct=0.4)
```

## 11. 注意事项

1. **低波动时暂停**: ATR/价格比 < 0.05% 时建议不交易, 避免无效磨损
2. **交易时段**: 建议在流动性好的时段运行 (亚洲开盘、欧美重叠)
3. **品种选择**: BTC 主流币流动性好; 山寨币波动大信号更多但滑点也大
4. **数据质量**: 需 OHLCV 完整, 缺失 K 线会导致均线计算偏差
5. **执行延迟**: 1 分钟级别对延迟敏感, 建议 colocation 或低延迟 API
6. **过拟合风险**: 参数在 ±30% 范围内稳定, 但未在更长历史数据上验证
