# QUANTOS 愿景:动态自治研究操作系统(Dynamic Self-Governing Research OS)

> 2026-06-29 记录。把 "QUANT-OS 应是一个动态执行、持续自我完善的系统" 这一方向固化下来。
> 这是与真实度补完(Phase 1B-5)并行的另一条主线,不替代它。

## 一句话

QUANTOS 不只是一台量化机器,而应是一个**有特权分级的动态自治系统**——像真 OS 一样有内核态/用户态、保护环、受控入口。**自我进化的是"它做研究的能力",自我完善结构走的是"人工把关的特权通道"。** 这条分级线,正是它能托管真金白银、又不炸掉的根本。

## 三个环(自我完善的特权分级)

| 环 | 自治程度 | 范围 | 现状 |
|---|---|---|---|
| **用户态 / Ring 3** | 全自动(且应该) | 研究工厂:取数→清洗→归类→搜因子→回测→验证;元学习(bandit 学有效搜索方向、退役衰减因子、正交发现逼新 edge) | 真骨架已在:`session.run_research_session`、`ResearchAgentLoop` 的 UCB bandit 跨会话持久、`degradation_monitor`、正交 `basis_returns` |
| **自诊断层 / Ring 1** | 自动观察 + 人工动手 | 系统照镜子:扫自身代码、跑治理扫描、检测缺口/漂移/坏模块,产出诚实待办,甚至起草修复+测试。改代码必须过人工+CI+治理扫描 | 9 智能体审计就是这件事(现人工触发,可做成定时自检) |
| **内核态 / Ring 0** | 永远人工 | 风控门、安全配置、晋级闸门、凭证、实盘开关 | `governance scanner` = 安全启动/代码签名,机器拦死任何往这层塞券商SDK/下单/翻flag的改动 |

## 为什么这条线是"特性"不是"残缺"

一个能改写自己适应度函数 / 风控门的系统,迟早**奖励黑客**——发现"骗过自己的评估"比"真赚钱"容易,于是拆掉自己的熔断器。这是 Goodhart 定律,是自动化系统在金融里炸掉的头号死法。教训已有缩小版:4h 加密因子样本内 DSR 0.586、无窥视样本外 0(纯过拟合)。**让机器又搜索又评判自己的搜索,它必然过拟合自己。** 所以:
- 改**研究产出** → 能,越自动越好。
- 诊断**自身缺陷** → 能自动发现+提议。
- 改**安全/风控/晋级代码** → 永远人工+审计+治理扫描。

## 两条可建主线(并行于 Phase 3-5)

1. **研究编排器**(用户态自动化):边界层调度器(像 research_runner,不进 services 核心),定时 拉新数据→增量入库→重跑搜索→记录→刷新;带反馈闭环(衰减监控 + 正交奖励);**严格多重检验会计**(experiment_registry 跨进程持久试验次数+var_sr,自动搜索不能偷偷膨胀假阳性)。
2. **自诊断回路**(自我观察):定时自动跑 审计+治理扫描+完整度评估,产出系统自己的缺陷/待办工单,推人工台——系统给自己开工单,人来批。

## 不可动摇的红线(贯穿全程)

机器只研究、人才能批准;`auto_approved=0`;非人类 agent 到不了 APPROVED;不引券商SDK、不下单、不碰凭证;services/ 核心无网络、确定性;网络/调度只在边界层。L2_DRY_RUN_ONLY。
